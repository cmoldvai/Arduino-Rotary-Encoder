## [1.0.0] - 2026-11-10

### Added
- Firmware for reading two quadrature rotary encoders and a pushbutton.
- Serial output for encoder direction and button press/release events.
- PlatformIO configuration for the ATmega328P-based Adafruit Metro.
- Project README with wiring and build instructions.
